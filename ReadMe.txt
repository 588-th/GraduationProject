To launch the project and work with artificial intelligence, you need to install three libraries:

SciSharp.TensorFlow.Redist 2.16.0
TensorFlow.Keras 0.15.0
TensorFlow.NET 0.150.5

They can be installed via NuGet.

They must be installed depending on the "Backend" project.

After installing and building the project, the libraries should also appear in the "bin" folder of "Frontend" and "UnitTests" project dependencies and in the "packages" folder.

At the root there is a png image "Libraries" with a hint.
